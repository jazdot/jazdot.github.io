# CAT 2026/27 Syllabus Reference — Complete Topic Coverage

## Exam Format (as of CAT 2024–2025 trend)

- **Duration**: 120 minutes (40 min per section)
- **Total Questions**: 66 (VARC: 24 | DILR: 20 | QA: 22)
- **Sectional Time Limit**: STRICT — cannot skip between sections
- **Negative Marking**: MCQ = -1 per wrong. TITA = 0 (no penalty)
- **TITA Share**: ~30% of total questions

---

## Section 1: VARC (Verbal Ability & Reading Comprehension)

### Reading Comprehension (16 questions = 4 passages × 4 questions)

**Passage Characteristics:**
- Length: 450–700 words
- Style: Abstract, analytical, argumentative (NOT narrative)
- Sources comparable to: The Economist, Aeon, Atlantic, Nature, Foreign Affairs
- CAT 2026 trend: Increasing philosophy and cross-disciplinary content

**Domain Rotation (typically one each):**
1. Philosophy / Metaphysics / Epistemology
2. Social Science / Political Theory / Sociology
3. Economics / Business / International Relations
4. Science / Technology / Environment / Cognitive Science
5. Literature / Culture / Anthropology (occasional)

**Question Type Frequency:**
- Inference questions: 40% (most common — must read between lines)
- Main Idea / Central Theme: 20%
- Author Tone/Attitude: 15%
- Para Function: 10%
- Vocabulary in Context: 8%
- Fact / Detail (direct): 7% (least common, and easiest)

**RC Solving Hierarchy (teach in training):**
1. Read opening + closing paragraphs first
2. Map the author's primary claim
3. Identify what they're FOR vs AGAINST
4. For inference: eliminate answers that go beyond text or contradict tone

---

### Verbal Ability (8 questions, mostly TITA)

**Para Jumbles — 4 questions (TITA)**
- 6 sentences given (labeled 1–6)
- Sentence 1 = fixed opener, Sentence 6 = fixed closer
- Student types sequence of middle 4 sentences
- Key skills: pronoun reference, connectives, cause-effect, contrast markers

**Para Summary — 2 questions (MCQ)**
- A paragraph of 150–200 words
- 4 options: pick the best one-sentence summary
- Wrong options: too broad, too narrow, wrong tone, adds external info

**Odd Sentence Out — 2 questions (TITA)**
- 5 sentences on a common theme
- One breaks the logical/topical flow
- Student types the number (1–5) of the outlier

## Section 2: DILR (Data Interpretation & Logical Reasoning)

### Format: 4 Sets × 5 Questions Each

**DI Set Types (2 sets expected):**

| Type | Frequency | Core Skill |
|---|---|---|
| Caselet / Text DI | Very High | Extract + compute from unstructured data |
| Table with Conditions | High | Row-column operations with hidden constraints |
| Stacked Bar / Grouped Bar | Medium | Comparative proportion analysis |
| Line Graph (multi-variable) | Medium | Rate of change, trend interpretation |
| Pie Chart + Secondary Source | Low | Cross-reference two data sources |
| Network / Flow Data | Emerging | Directional graph reading |

**LR Set Types (2 sets expected):**

| Type | Frequency | Core Skill |
|---|---|---|
| Binary Logic | High | Truth-value reasoning, liar/truth-teller |
| Game & Tournament | High | Knockout/league table construction |
| Matrix Grid (Assignment) | High | Constraint elimination |
| Linear/Circular Arrangement | Medium | Positional logic with attributes |
| Scheduling | Medium | Time-slot / day-slot assignment |
| Route-based | Low | Path optimization |

**DILR Set Design Principles:**
- Questions within a set share context and build on each other
- Q1 should be independently solvable
- Q4–Q5 typically require reconstructing partial information from Q1–Q3
- "If-then" hypothetical questions appear in ~60% of sets

### Arithmetic — Full Subtopic Coverage

**Time, Speed & Distance:**
- Train crossing (platforms, poles, trains)
- Relative speed (same direction, opposite)
- Average speed (critical error trap)
- Circular tracks — meeting points
- Boats & Streams — upstream/downstream

**Work & Time:**
- Pipe & Cistern (filling/draining rates)
- Men-Days equivalence
- Alternate days working
- Efficiency ratios

**Percentages + Profit & Loss:**
- Successive discounts
- Marked price / SP / CP relationships
- Dishonest weighing
- Partnership profit split

**Mixtures & Alligations:**
- Cross-method setup
- Multiple replacements
- Three-ingredient mixtures

**SI & CI:**
- Effective annual rate
- Difference between SI and CI for n years
- Population growth models

---

### Algebra — Full Subtopic Coverage

**Equations:**
- Parametric solutions (when roots are integers)
- Sum / Product of roots (Vieta's formulas)
- Condition for equal roots (discriminant)

**Progressions:**
- nth term, Sum formulas for AP, GP, HP
- Infinite GP sum
- AGP (Arithmetic-Geometric Progression)

**Inequalities:**
- AM ≥ GM ≥ HM (application, not proof)
- Sign chart method for rational inequalities
- Modulus-based inequalities

**Logarithms:**
- Base change formula
- Properties: log(mn), log(m/n), log(m^n)
- Characteristic and mantissa

---

### Geometry — High-Yield Sub-areas

**Triangles:**
- Congruence (SSS, SAS, ASA, RHS)
- Similarity — ratio of areas, medians, angle bisectors
- Pythagoras + common triples (3-4-5, 5-12-13, 8-15-17)
- Incentre, Circumcentre, Centroid, Orthocentre properties

**Circles:**
- Chord-angle-arc relationships
- Tangent-radius (perpendicular property)
- Two-chord angle theorem
- Tangent from external point

**Coordinate Geometry:**
- Section formula (internal, external division)
- Area of triangle given vertices
- Line equations: slope, intercept, distance from point
- Concurrence of three lines

---

### Number System — Key Concepts

**Remainders:**
- Cyclicity of unit digits (2→4, 3→4, 7→4, 8→4, 9→2)
- Fermat's Little Theorem: a^(p-1) ≡ 1 (mod p), p prime
- Wilson's Theorem: (p-1)! ≡ -1 (mod p)
- Euler's Totient for composite bases

**Factors:**
- Total factor formula: (a+1)(b+1)(c+1)... for n = p^a × q^b...
- Sum of factors formula
- Even/Odd factors count

**HCF & LCM:**
- Product property: HCF × LCM = Product (for 2 numbers only)
- HCF by Euclid's algorithm
- LCM word problems (periodic meeting)

---

### Modern Math — Compact Coverage

**Permutations & Combinations:**
- Arrangements with repetition / without repetition
- Circular arrangements: (n-1)!
- Derangements: D(n) = n!(1 - 1/1! + 1/2! - ... ± 1/n!)
- Distribution into distinct / identical boxes

**Probability:**
- Classical (equally likely outcomes)
- Conditional: P(A|B) = P(A∩B)/P(B)
- Bayes' Theorem (2-event version)
- Geometric probability (area-based)

**Set Theory:**
- Inclusion-Exclusion for 2 and 3 sets
- Venn Diagram with 3 overlapping sets
- Exactly-one, exactly-two counting

---

## Training Module Sequence (Recommended Order)

### QA Learning Path
1. Number System (base concepts) → Factors → Remainders → HCF/LCM
2. Arithmetic: Ratio → % → P&L → Mixtures → TSD → Work-Time → SI/CI
3. Algebra: Linear Eq → Quadratic → Progressions → Logs → Inequalities
4. Geometry: Triangles → Circles → Coordinate → Mensuration
5. Modern Math: PnC → Probability → Set Theory

### DILR Learning Path
1. Tables → Bar Charts → Line Graphs → Caselets
2. Linear Arrangement → Circular → Matrix Grid → Binary Logic → Tournaments

### VARC Learning Path
1. RC: Main Idea → Inference → Tone → Para Function
2. VA: Para Summary → Odd Sentence Out → Para Jumbles
