## 🚀 Overview

Welcome to the source code of my personal portfolio! As a **Network & MLOps Engineer**, I wanted my website to be more than just a static resume. Instead, it serves as a live demonstration of my frontend, infrastructure, and automation capabilities.

This project is a **Progressive Web App (PWA)** that features hardware-accelerated animations, simulated networking tools, and interactive data visualizations.

🔗 **Live Site:** [jazdot.github.io](https://jazdot.github.io)

---

## ✨ Key Features

- **Interactive Network Topology:** A custom drag-and-drop `React Flow` implementation visualizing an O-RAN 5G deployment and UAV Mesh swarm.
- **MLOps Pipeline Visualizer:** A fully animated, simulated CI/CD pipeline traversing data ingestion, training, containerization, and edge deployment with real-time log outputs.
- **Ping & Traceroute Simulator:** A built-in terminal tool designed to query edge functions and simulate network reachability.
- **Career Topology Map:** A dependency-free, animated SVG map tracing career trajectory nodes across an active radar grid.
- **Zero-Asset Sound Design:** A synthesized "bloop" effect generated purely via the browser's native `Web Audio API` when toggling the Dark/Light theme.
- **App-Like PWA:** Full offline support, mobile installability, and a custom Service Worker implementation that prompts users when a new version of the code is deployed.
- **Performance Optimized:** Route-based code splitting (`React.lazy` / `Suspense`) and aggressive caching ensure sub-second initial load times despite heavy visual effects.

## 💻 Local Development

Want to run this locally? 

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jazdot/jazdot.github.io.git
   cd jazdot.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
